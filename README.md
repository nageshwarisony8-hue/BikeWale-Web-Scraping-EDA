# BikeWale Web Scraping & EDA

## Project Overview

This project focuses on collecting and analyzing motorcycle data from BikeWale using web scraping and Python.

The analysis explores bike prices, brands, engine capacity, mileage, power, weight, ratings, and other buyer-oriented attributes.

## Objectives

- Collect structured bike information through web scraping
- Clean and preprocess the scraped data
- Compare brands, models, prices, and specifications
- Analyze engine capacity, mileage, power, and weight
- Explore ratings and reviews
- Identify market variations across bike brands and price segments

## Dataset

- **Source:** BikeWale
- **Number of Listings:** 442
- **Key Fields:** Brand, Model, Price, Engine, Mileage, Power, Weight, Rating and Reviews

## Tools & Technologies

- Python
- Pandas
- NumPy
- Regex
- BeautifulSoup
- Requests
- Exploratory Data Analysis (EDA)

## Project Workflow

**Website → Web Scraping → Data Cleaning → Exploratory Data Analysis → Market Insights**
